# PriceMarket
PriceMarket is a personal project of mine which helps you find the optimal way to shop at supermarkets. 
You create a list of everything you want to buy(all products available in the biggest greek supermarkets),and according to your location and proximity to these supermarkets it recommends you the best route,visit one or multiple supermarkets using an algorithm which takes into account distance,time to travel and cost of fuel prices.

The backend is written in C#,the database is currently in SQLite and the frontend is on HTML and CSS.
Minimal APIs are used to communicate info.
